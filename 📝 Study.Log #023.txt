📚 Aprendi:
• Enum permite criar uma lista de opções fixas, deixando o código mais organizado e legível;

• Struct é um tipo de valor usado para agrupar pequenos conjuntos de dados relacionados um a o outro;

• Structs são copiadas quando atribuídas a outra variável, enquanto classes compartilham a mesma referência;

• Exceções servem para tratar erros que podem acontecer durante a execução do programa, evitando que ele seja encerrado inesperadamente durante o teste;

• O bloco try contém o código que pode gerar uma exceção, e o catch é executado caso uma exceção realmente aconteça.
